01 · WINDOWS

Windows

Open Selah in an Edge app window. You can also install the PWA from Edge's app menu.

  1. Download and extract the launcher ZIP.
  2. Run Launch-Selah.cmd.
  3. Optionally create Start menu and desktop shortcuts.
Download the Windows launcher ZIP · build 19 Installation details and SHA-256 checksum

Microsoft Edge and an internet connection for the first launch are required. The launcher is not an EXE/MSIX or Microsoft Store app.

02 · MAC

Mac

On macOS Sonoma 14 or later, add Selah from Safari to your Dock to open it like an app.

  1. Open Selah in Safari.
  2. Choose File → Add to Dock or Share → Add to Dock.
  3. Confirm the name and add the web app.
Open Selah in Safari

The current public Mac install method is Safari's web app. A separate signed and notarized Mac installer is not published here.

03 · IPHONE

iPhone

Add Selah to your Home Screen from Safari and open it from its app icon.

  1. Open Selah in Safari.
  2. Tap Share, then choose Add to Home Screen.
  3. If shown, turn on Open as Web App and tap Add.
Open Selah in iPhone Safari

This is the web app. A separate iOS App Store listing or IPA download is not currently published.

One service, your devices

All three devices open the same Selah Scripture and reflection service. Sign in to sync supported records. Notes saved before signing in stay in that app's local storage; use Selah's export and import backup to move them where needed.

You can install and start using Selah now. Separate Apple App Store and Microsoft Store listings are not currently available; this page does not claim store availability.

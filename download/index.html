마태복음을 읽고, 시간을 정해 묵상하고, 깨달은 내용과 기도를 기록하세요. 직접 만드는 복습 퀴즈로 말씀을 다시 돌아볼 수 있습니다.

성경 읽기 시작 시간 묵상 시작

01 · WINDOWS

Windows

Edge 앱 창에서 Selah를 열어 빠르게 실행하세요. 기존 Edge 설치 메뉴로 PWA를 추가할 수도 있습니다.

  1. 런처 ZIP을 받고 압축을 풉니다.
  2. Launch-Selah.cmd를 실행합니다.
  3. 원하면 시작 메뉴·바탕 화면 바로가기를 만드세요.
Windows 런처 ZIP 받기 · build 19 상세 설치 안내와 SHA-256 체크섬

Microsoft Edge와 첫 실행 시 인터넷 연결이 필요합니다. 이 런처는 EXE/MSIX나 Microsoft Store 앱이 아닙니다.

02 · MAC

Mac

macOS Sonoma 14 이상에서 Safari의 Dock 웹앱으로 추가하면 Dock과 Spotlight에서 열 수 있습니다.

  1. Safari에서 Selah 웹앱을 엽니다.
  2. 공유 메뉴 또는 파일 메뉴에서 Dock에 추가를 선택합니다.
  3. Selah를 확인하고 추가합니다.
Safari에서 Selah 열기

현재 공개된 Mac 설치 방법은 Safari 웹앱입니다. 별도 서명·공증된 Mac 설치 파일은 이 페이지에서 배포하지 않습니다.

03 · IPHONE

iPhone

Safari에서 Selah를 홈 화면에 추가하면 아이콘으로 앱처럼 열 수 있습니다.

  1. Safari에서 Selah 웹앱을 엽니다.
  2. 공유 버튼을 누르고 홈 화면에 추가를 선택합니다.
  3. 필요하면 웹 앱으로 열기를 켠 뒤 추가합니다.
iPhone Safari에서 Selah 열기

이 설치 방법은 웹앱입니다. 별도 iOS App Store 앱이나 IPA 파일은 아직 공개하지 않았습니다.

한 서비스, 내 기기들

세 기기 모두 같은 Selah 말씀 읽기·묵상 서비스를 엽니다. 지원 기록을 계정으로 동기화하려면 로그인하세요. 로그인 전 기록은 앱별 저장 공간에 남으니 기기를 옮길 때는 Selah의 백업 내보내기·가져오기를 이용할 수 있습니다.

지금 바로 설치해 시작할 수 있습니다. Apple App Store, Microsoft Store용 별도 앱 등록은 현재 제공되지 않습니다. 플랫폼별 스토어에서 내려받을 수 있다고 표시하지 않습니다.

# Reina-Valera 1909

- Edition: Reina-Valera 1909, Castilian Spanish.
- Distribution status: CrossWire lists the SpaRV module as Public Domain. This is an older historical edition; rights can differ by jurisdiction.
- Official text and downloadable formats: <https://ebible.org/bible/details.php?id=spaRV1909>.
- CrossWire distribution listing: <https://www.crosswire.org/sword/modules/ModInfo.jsp?modName=SpaRV>.
- The bundled text was normalized into one JSON file per canonical book from ScrollMapper's `SpaRV` dataset (pinned commit `e1b254cef86d0e65b1a5d1a94b8b112d0f296a2c`) and checked against eBible's official USFM download. Verse wording was not translated or paraphrased by Selah.
- The edition's source data contains 18 numbered verse positions with no text. Selah leaves these positions empty and labels them in the reader rather than borrowing wording from another edition.
- Source checksums are recorded in `manifest.json`.
